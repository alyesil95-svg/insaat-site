# Frontend Design Skill

## Goal
Create luxury, premium, cinematic web experiences that impress clients.

## Design Rules
- Color palette: white, black, gold (#C9A84C)
- Typography: Cormorant Garamond for headings (weight 200), Inter for body (weight 300)
- Animations: smooth, slow, cinematic - GSAP ScrollTrigger
- Layout: full-screen sections, fixed video backgrounds
- Mobile responsive

## Technical Stack
- Next.js 14+ App Router
- Tailwind CSS
- GSAP + ScrollTrigger
- Framer Motion

## Sections Required
1. Hero - fullscreen video scrubbing background
2. Projects - luxury construction projects with 3D animations
3. Services - what we build
4. Why Us - stats and trust
5. References - client testimonials
6. Contact - elegant form
